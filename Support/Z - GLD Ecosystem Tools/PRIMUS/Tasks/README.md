# Tasks


This folder contains three tasks corresponding to scheduled processes. Task 1 involves uploading GLD surveys that have yet to be uploaded or updated in the *datalibweb* and confirming them into PRIMUS. Task 2 is a follow-up to task 1 to approve the data -- at this stage, the data will appear and be ready for use in *datalibweb*. Task 3 cleans up the log files and temporary files that were created from task 1.
